Hey again! I think I found the fix for the levels on nameplates losing their colors in the hub as well that I talked about in the modding discord.

I'm not exactly finished as I think part might still be broken.

So on line 870 (I believe, might've added a comment somewhere when I was testing stuff that moved this line around) in ColorSelection.lua it reads:
local clean_name_part = name_part:gsub("{#color%([^%)]*%)}", ""):gsub("{#reset%(%)}", "")


Because of no carrot at the beginning of {#color%([^%)]*%)} this removes all color tags on the nameplate rather than just one that might be recoloring the name or class icon, causing True Level to lose its colors. The fix is just adding that carrot:
local clean_name_part = name_part:gsub("^{#color%([^%)]*%)}", ""):gsub("{#reset%(%)}", "")


Now the part that I believe is technically still broken. Line 860 (again might be off a little on the line number here) reads:
local escaped_name = player_name:gsub("([%(%)%.%%%+%-%*%?%[%]%^%$])", "%%%1")


This causes a hyphenated name like Haken-Veil to become Haken%-Veil, which I believe in theory, would cause issues later in the code. 
I'll try to explain in comments (starts at EDIT:) why I think this might be an issue below:
