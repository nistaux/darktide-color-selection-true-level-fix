# Build an independent companion mod

The project will build an independently maintained Companion Mod, publicly named **Color Selection – True Level Compatibility Fix**, that integrates with the creator-maintained Color Selection and True Level mods instead of continuing to edit a private Color Selection copy. This keeps upstream updates installable without manually merging Austin's changes each time and avoids redistributing replacement upstream files; the preserved customized and newer patched snapshots remain reference evidence for reconstructing the desired behavior and evaluating compatibility risks.
